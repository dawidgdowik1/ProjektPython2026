\chapter{Podsumowanie i wnioski}

W ramach projektu udało się stworzyć działający program do zarządzania produktami w sklepie internetowym. Aplikacja została napisana w języku Python z wykorzystaniem programowania obiektowego i pozwala użytkownikowi na wygodną obsługę przez menu w konsoli.

\section{Wnioski końcowe}
Podczas pisania i testowania programu udało się sformułować następujące wnioski:
\begin{itemize}
    \item \textbf{Wykorzystanie obiektowości}: Dzięki zastosowaniu dziedziczenia i polimorfizmu cały kod jest dobrze poukładany. Program potrafi bez problemu zarządzać różnymi typami produktów (elektronika i odzież) w ramach jednej wspólnej listy.
    \item \textbf{Bezpieczeństwo i walidacja}: Hermetyzacja, czyli użycie getterów i setterów, pozwoliła skutecznie zabezpieczyć program przed błędami. System sam pilnuje, żeby nikt nie wpisał ujemnej ceny i automatycznie poprawia ją na zero.
    \item \textbf{Skrócenie kodu}: Użycie list składanych (\textit{list comprehensions}) do filtrowania asortymentu sprawiło, że kod jest o wiele krótszy, bardziej czytelny i działa szybciej niż tradycyjne, długie pętle.
\end{itemize}

\section{Możliwości rozwoju programu}
Przygotowana struktura aplikacji pozwala na jej łatwą rozbudowę w przyszłości. Program można w prosty sposób rozwinąć o dodatkowe funkcjonalności, takie jak:
\begin{itemize}
    \item Zapisywanie i wczytywanie produktów z plików zewnętrznych, na przykład w formacie JSON lub tekstowym.
    \item Stworzenie okienkowego interfejsu użytkownika (GUI) zamiast czarnej konsoli, na przykład przy użyciu wbudowanej biblioteki Tkinter.
\end{itemize}

Podsumowując, aplikacja spełnia wszystkie założenia projektowe, działa stabilnie i poprawnie reaguje na podstawowe błędy użytkownika. Stanowi ona dobrą bazę pod większy system e-commerce.
